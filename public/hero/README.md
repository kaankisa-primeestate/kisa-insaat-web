# Hero fotograflari

Ana sayfanin ustundeki tam ekran arka planda donen fotograflar bu klasore konur.

Onerilen olcu: **en az 2400x1350 piksel**, yatay (16:9 civari), JPG.
1 ile 5 arasi fotograf idealdir.

Dosyalari buraya ekledikten sonra `src/content/hero.ts` icindeki listeye
yolunu ve aciklamasini yazin:

```ts
export const heroImages: HeroImage[] = [
  { src: "/hero/ebru-apartmani.jpg", alt: "Ebru Apartmani dis cephe goruntusu" },
];
```
